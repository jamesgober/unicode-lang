# unicode-lang v1.1.0: Invisible characters

**Minor.** v1.1.0 adds two functions that find characters which render as nothing, so a lexer can catch identifiers that hide them. Nothing existing changes: every 1.0 function returns what it returned before.

## What is unicode-lang?

The Unicode text primitives a language front end needs: identifier rules (UAX #31), display width (UAX #11), and all four normalization forms (UAX #15), from compact tables generated directly from the Unicode Character Database (16.0.0). No third-party dependencies, `no_std`, and fully safe (`#![forbid(unsafe_code)]`).

## Why

UAX #31 admits some invisible characters into identifiers. ZERO WIDTH JOINER (U+200D) and ZERO WIDTH NON-JOINER (U+200C) are `XID_Continue`, because some scripts need them, and the Hangul fillers U+3164 and U+FFA0 are `XID_Start`. So `is_xid("admin\u{200D}")` is `true`, and that name looks exactly like `admin` in any editor. A lone `\u{3164}` is a valid identifier that looks blank. NFC and NFKC leave these characters in place.

That is what the standard says, so `is_xid` is unchanged. What was missing was a way to find them.

## Added

- `is_default_ignorable(c: char) -> bool`: `true` for characters with the `Default_Ignorable_Code_Point` property. That covers the zero-width space and joiners, the word joiner, the byte order mark, the Hangul fillers, variation selectors, tag characters, SOFT HYPHEN and a few more. ASCII is answered without a table lookup.
- `first_default_ignorable(s: &str) -> Option<(usize, char)>`: the byte offset and value of the first such character in `s`. Pure-ASCII strings return `None` without decoding.

```rust
use unicode_lang::{first_default_ignorable, is_xid};

let spoofed = "admin\u{200D}";
assert!(is_xid(spoofed));
assert_eq!(first_default_ignorable(spoofed), Some((5, '\u{200D}')));
```

The policy stays with the caller. A language that needs ZWNJ in Persian identifiers can allow that one character and reject the rest.

The table is generated from the pinned `DerivedCoreProperties.txt` by `dev/gen_tables.rs`, like every other table, and adds 17 ranges.

## Not yet

Mixed-script and confusable detection (UTS #39) needs `Scripts.txt`, `ScriptExtensions.txt`, `IdentifierStatus.txt` and `confusables.txt` added to the pinned data set. It is on the roadmap for a later 1.x release.

## Compatibility

Additive only. MSRV stays at Rust 1.85.
